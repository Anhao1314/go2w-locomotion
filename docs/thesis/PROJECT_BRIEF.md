## 1. 选题是怎么来的

在前期学习中我注意到一个矛盾：**分层架构（高层出指令、底层管关节）在机器人工程里被普遍使用，但几乎没有公开工作提供严格的受控对比**——现有分层四足论文（如 Jain et al., IROS 2019）只报告自己架构的成功率，不提供同任务、同观测、同训练预算的端到端单层基线。也就是说，"分层到底值不值"这个工程上每天都在做的选型判断，缺少数据支撑。

我据此确定了研究问题：**在同一任务、同一观测、同一训练预算下，量化分层与端到端架构在成功率、样本效率、失败可归因性上的差异**。

## 2. 我已经做了什么（预实验，全部可复核）

按预注册实验协议（评估种子、指标、阈值在训练前冻结；负结果保留）完成了：

| 实验 | 结果 |
| --- | --- |
| 底层 locomotion 策略（Go2，Isaac Lab，PPO，2048 并行） | 3 个训练种子全部达标：速度跟踪误差 0.0569±0.0011 m/s（阈值 0.15），零摔倒 |
| L1 简单任务受控对比 | 两种架构都 100% 成功；分层收敛快 3 倍（50 vs 150 迭代） |
| **L3 长程任务受控对比（每组 3 训练种子）** | **分层 3/3 种子 100 迭代收敛到 100%；单层仅 1/3 种子成功（450 迭代），其余 1500 迭代完全失败** |
| 失败归因 | 单层不收敛的种子全部死在"行走→原地转向"的步态切换处（阶段到达率定位）；分层无需学转向步态 |

**一个值得说明的方法论发现**：只跑 seed 2 会得出"单层也行只是慢 4.5 倍"，只跑 seed 0/1 会得出"单层完全不可行"——两个结论都错。多种子验证不是锦上添花，而是结论正确性的前提。这一点改变了我的主结论的表述方式（从"成败差异"修正为"可靠性与效率的双重优势"）。
